# gamifica-o-Hackaton

Plataforma de gamificação desenvolvida durante um hackathon, com React, TypeScript e Vite.

## Stack

- React
- TypeScript
- Vite
- ESLint

## Como rodar localmente

```bash
git clone https://github.com/EduardoAlkimim/gamifica-o-Hackaton.git
cd gamifica-o-Hackaton
npm install
npm run dev
```
